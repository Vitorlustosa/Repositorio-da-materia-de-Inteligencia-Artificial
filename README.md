# Inteligência Artificial (FGA0221)

Projetos desenvolvidos durante o semestre de **2025.2** na **Universidade de Brasília (UnB — FGA)** para a disciplina de Inteligência Artificial.

## Sobre a Disciplina

A disciplina teve como objetivo capacitar o aluno no desenvolvimento de sistemas inteligentes, explorando os pilares de:
- **Resolução de problemas e busca**
- **Representação do conhecimento e raciocínio**
- **Tratamento de incerteza e inferência probabilística**
- **Métodos modernos de aprendizado de máquina**

---

## Módulos do Repositório

A documentação detalhada e os scripts de cada etapa estão separados em páginas dedicadas:

- 📂 **[Projeto 1: Busca e Conhecimento](projeto1/README.md)**  
  Algoritmos de busca em grafos (BFS e A*), satisfação de restrições (Backtracking e CSP), algoritmos genéticos e sistemas especialistas.

- 📂 **[Projeto 2: Tratamento de Incerteza](projeto2/README.md)**  
  Modelagem probabilística com Redes Bayesianas, processos estocásticos com Cadeias de Markov e atenuação de ruído sensorial com Filtro de Kalman 3D.

- 📂 **[Projeto 3: Aprendizado de Máquina](projeto3/README.md)**  
  Técnicas de aprendizado supervisionado (Regressão Linear), não supervisionado (K-Means), por reforço (Q-Learning) e deep learning (MobileNetV2).

## Instalação Rápida

```bash
# Clonar o repositório
git clone https://github.com/Vitorlustosa/Repositorio-da-materia-de-Inteligencia-Artificial.git
cd Repositorio-da-materia-de-Inteligencia-Artificial

# Criar e ativar o ambiente virtual
python -m venv .venv
# Windows:
.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate

# Instalar dependências
pip install -r requirements.txt
```
